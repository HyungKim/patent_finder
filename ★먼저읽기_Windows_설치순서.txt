★먼저읽기 - Windows 설치 순서

이 프로그램은 PPTX, PDF 보고자료에서 특허 출원 검토가 필요해 보이는 구간을 찾아 표시합니다.
인터넷 없이 설치되고, 분석도 이 PC 안에서만 합니다.

■ 처음 설치할 때

  1) GitHub 의 Releases 에서 설치 묶음 zip 을 받습니다.
       https://github.com/HyungKim/patent_finder/releases
     (초록 Code 버튼의 Download ZIP 이 아닙니다. 거기에는 설치 패키지와 모델이 없습니다)

  2) zip 을 우클릭 -> "모두 압축 풀기". 풀린 폴더 안의 patent_finder 폴더를 D:\ 로 옮깁니다.
     D:\patent_finder 안에 setup.bat, src, models, vendor 가 보이면 맞습니다.
     (C:\ 에 두어도 됩니다. 폴더 안의 상대 위치만 보고 동작합니다)

  3) setup.bat 더블클릭.
     검은 창에 [1/4] ~ [4/4] 가 차례로 나오고 "설치 완료!" 가 보이면 끝입니다.
     백신 프로그램이 차단 메시지를 띄우면 "허용" 을 누릅니다.

■ 쓸 때

  분석      mark.bat 더블클릭 -> 파일 열기 창에서 PPTX, PDF 파일을 고릅니다 (Ctrl, Shift 로 여러 개).
            폴더째 분석하려면 파일이나 폴더를 mark.bat 아이콘 위에 끌어다 놓습니다.
            끝나면 결과 폴더가 열립니다.
              report.html   표시된 구간 목록
              marked        표시가 들어간 PPTX, PDF 사본
            원본 파일은 바뀌지 않습니다. 결과는 D:\patent_finder\outputs 에 쌓입니다.

  검토 화면  run.bat 더블클릭 -> 브라우저가 열립니다. 표시된 구간에 YES / NO 판정을 남길 수 있습니다.
            끝낼 때는 검은 창을 닫습니다.

■ 필요한 것

  Python 3.11, 3.12, 3.13 (64비트) 중 하나가 이 PC 에 설치되어 있어야 합니다.
  없으면 setup.bat 이 설치된 Python 목록을 보여 주고 멈춥니다.

■ 안 될 때

  setup.bat 의 검은 창에 나온 [실패] 줄과 그 아래 안내를 그대로 적어 두세요.
  자세한 설명은 docs\OFFLINE_INSTALL.md 에 있습니다.

■ 알아둘 점

  표시는 "검토해 볼 후보" 입니다. 처음에는 합성 예문으로 만든 임시 분류기가 판정하므로
  놓치는 것도 있고 잘못 표시하는 것도 있습니다. 검토 화면에서 판정을 쌓으면 회사 문서에 맞게 학습할 수 있습니다.
